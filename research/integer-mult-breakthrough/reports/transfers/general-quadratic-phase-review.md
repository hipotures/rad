The coordinator proposed extending the old nondegenerate-subspace frames to

## Exact phase family and canonical difference

For a symmetric matrix A over F2, define

```text
q_A(x) = sum_i A_ii*x_i + 2*sum_(i<j) A_ij*x_i*x_j  (mod 4),
K_q = 2^(-h) F diag(i^q) F,
F_(y,x) = (-1)^(y dot x).
```

The Fourier matrices in this definition are an identity oracle for the
review; the implementation below does not execute them. It uses the dyadic
two-point kernel C with diagonal `(1+i)/2` and off-diagonal `(1-i)/2`.

The phase satisfies
`q(x+y)-q(x)-q(y)=2*x^T*A*y (mod 4)`, where addition in its arguments is XOR.
Adding `2*ell dot x` leaves the polar matrix unchanged and closes the family
under the required changes of basis and frame differences.

An actual change from canonical frame A to canonical frame B is

```text
K_B K_A^(-1) = K_(q_D + 2*ell dot x),
D = A xor B,
ell_i = [A_ii=1 and B_ii=0].
```

In particular, a rank computation on D is not enough: the deleted diagonal
entries contribute a linear phase. The finite control rejects replacing an
inverse identity frame by the forward identity frame through omission of
this correction.

## A congruence proof with only one dyadic child

Write `r=rank(A)`. Binary Gram elimination first splits off vectors of
self-pairing one, then alternating two-dimensional blocks, and finally the
radical. A nonalternating nonsingular form is congruent to `I_r`: a block
`I_1 + J_2` can be replaced by three mutually orthogonal norm-one vectors
`c+u, c+v, c+u+v`, where `B(u,v)=1`. This absorbs every residual alternating
block. A purely alternating nonsingular form is a sum of J-pairs and has
even r.

Choose the resulting full basis T. The physical address coordinates are
changed by `x -> T^T*x`; that is an explicit invertible address permutation.
The quadratic identity is determined by its polar form and its values on
this basis. On radical vectors the phase is even because
`q(v) mod 2 = B(v,v)`.

In the nonalternating case the transformed phase is

```text
q(T*z) = weight(z_0,...,z_(r-1)) + 2*ell' dot z  (mod 4).
```

Its kernel is one `C^tensor(r)` child followed by the address translation
`z -> z+ell'`. A negative selected direction can instead use
`C^(-1)=-i Z C Z`, so its translation can be traded for unit gauges. Radical
translation cannot in general be removed this way.

In the alternating case the transformed phase is

```text
q(T*z) = 2*sum_j z_(2j)*z_(2j+1) + 2*ell' dot z  (mod 4).
```

For one pair, the convolution kernel is
`(1/2)*(-1)^((x_1+y_1)*(x_2+y_2))`. Expanding its exponent expresses it as a
quadratic unit chirp on the input, the real normalized Hadamard on the
selected coordinates with each pair swapped, and a quadratic unit chirp on
the output. The radical coordinates remain unchanged before translation.

Let D multiply an address by `(-i)^weight` on these selected coordinates.
For even r, the real normalized Hadamard can be implemented through

```text
H_normalized,r = (-i)^(r/2) * D^(-1) * C^tensor(r) * D^(-1).
```

Every wrapper is a fourth-root unit. There is no irrational physical gate,
extra dyadic denominator, or coefficient amplification outside the child.
Using a separately normalized real Hadamard when r is odd would require
`1/sqrt(2)` and is invalid over Gaussian dyadics. The nonalternating case
uses C directly and avoids that problem.

For f columns in the old slot-major layout, apply T independently to every
column. The selected r slots form one contiguous interval of rf axes. The
single child is `C^tensor(rf)`, with the same complete record payloads and
all other axes retained. Chirps and signs aggregate to one fourth-root phase
per record. In the alternating case rf is even and the global unit is
`(-i)^(rf/2)`. Thus column batching introduces no irrational gauge or extra
recursive Gaussian call. Its physical routing is still required.

## A translation that cannot be hidden in a scalar gauge

The triangle adjacency matrix with columns `[6,5,3]` has rank two. Its
radical is generated by binary vector seven, and `q_A(7)=2`. The exact
Fourier kernel is supported on the affine coset `[1,2,4,7]`, excluding zero.
Every difference of addresses in that support lies in the image of A, but
the support itself is not that linear image.

Dropping the radical translation fails on the complete dirty payload. A
rank-r tensor child supported on a linear selected subspace cannot supply
this affine shift by itself. At rank zero, a general even linear phase is
a nontrivial address translation with no Gaussian child; calling it free
would also be false. A canonical A-to-A change is the identity, so this
rank-zero boundary does not manufacture an extra cost for unchanged
canonical frames.

## The ledger that still has to be paid

The exact auxiliary compilation has one rank-r bulk Gaussian child when
`r>0`, unit pointwise phase passes, and complete affine address permutations
before and after it. A pair-swap and affine translation may be combined with
the final invertible route. A payload field is never discarded or split off
from the recursive stream.

The old binary selected-bit router is a plausible implementation path for
the linear parts. Translation also needs a procedure. The pinned
`05-layers.tex` packed-selected-bit proof uses eight rotations with Boolean
controls. Setting each control to one flips the selected target bits while
restoring the arbitrary guard chunk. Deleting the source-bit tests should
preserve its displacement and exceptional-address repair bounds. This is a
specific proposed extension to prove and compile, not a free address map or
a completed routing theorem in this report.

If there are N complete records of u bits, pointwise phases require the
entire `N*u` payload scan. Address chirps take `O_h(e)` descriptor work per
record for fixed h and `e=h*f`. They cost `O(N*(u+e))`, and simplify to
`O(V)` only with an explicit sufficient record-length assumption such as
`u>=e`. The old superpolynomial-record family supplies a stronger condition;
it must be retained when reused. Arbitrary GL address permutations require
the paid binary routing bound rather than a random-access array claim.

No new elementary-denominator or magnitude charge is necessary for the unit
wrappers themselves. A full precision proof must nevertheless count child
dependency paths, scalar additions, copies, endpoint phases, and every actual
guard bit. At `r=h`, the child has the parent's selected width. The
[row-budget mechanism](same-width-row-budget.md) shows a possible analytical
way to terminate such calls, but a native complete-row allocation and its
changed precision guard are additional obligations.

Most importantly, this decomposition implements an individual frame change.
It does not construct scalar gates, source/sink phase conditions, dirty-bank
restoration, or a complete low-cost native network. The old local
nondegenerate-frame obstruction must not be reused as an obstruction to this
larger frame family, and a larger frame family must not be described as an
improved characteristic before its complete ledger exists.

uses a separately authored Gram congruence algorithm and literal Gaussian
dyadic arithmetic. It compares the compiled C-child program with exact
Fourier reference arrays, verifies the canonical frame-difference correction,
and restores every dirty input field by the inverse frame change.

The four-worker run checked 128 cases: all 64 symmetric three-by-three
matrices, sampled changed-frame pairs through dimension six, two-column bulk
cases, full and degenerate alternating forms, and explicit radical phases.

had alternating quotients and 21 had nonzero radical translations. It took
0.293 seconds. The negative controls reject omitted translation, omitted
canonical diagonal correction, omitted alternating global unit, and cropped
payload fields. These are exact finite arithmetic controls, not formal
verification of a native algorithm.
