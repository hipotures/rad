# Local target pivots escape the fixed terminal reader

The `j3/j4` actual-row decoders permit three destination-only sink copies to
be absorbed by three independently valued target pivots. All four or eight
source-basis banks, including every parked kernel bank, remain. The exact
local word preserves the original dirty target values and retained ancestor
old-response columns, and its literal chronological inverse restores every
input. A separate geometric witness shows that interleaving also avoids the
fixed terminal-reader premise on a concrete four-cube incidence.

This is a finite local component. It supplies no global pivot deadline,
complete Gaussian address replay, native recurrence or exponent. The frozen
eighteen package's
[`terminal-reader exclusion`](cap-dirty-completion-and-fanout-boundary.md)
remains valid within its stated whole-cube ordering. This result changes that
readout chronology, rather than contradicting the negative.

The compiler antecedent is the pinned [PR166 primary proof](https://github.com/CrocSwap/integer-mult-bounds/blob/4dbc2af5f223a0fbf22542c9d6c3f71442b6a3a6/research/paired-cube-target-accumulator/PROOF.md),
SHA-256 `36f5b7ffb9b6454b38d2c6f8934ca1c370512f1315220c129daf2f6c9fd2e8a6`.
The upstream proof credits Dumas and Grenet's *In-place accumulation of fast
multiplication formulae*, arXiv:2307.12712, for the scalar antecedent; this
package retains that attribution. It does not claim novelty for the scalar
cancellation identity or adopt an upstream multiplier bound. The independently
acquired proof, README and checker remain read-only in the recorded ignored
input directory. No upstream executable was imported or run.

The source is
[`cap_target_pivot_accumulation.py`](../../code/complex/cap_target_pivot_accumulation.py).
For each parity block, let `C` be the previously frozen four/eight-bank
invertible completion, and let `D` decode its first three actual rows into the
sixteen local target banks. Both `j3` and `j4` have an exclusive pivot for each
column of `D`: no other column affects it. The groups overlap only on the
nonpivot targets associated with the missing dependent row. The pivot read
coefficient is a unit sign, so no new odd divisor is introduced.

For channel `a`, choose pivot `p_a`, let `kappa_a=D[p_a,a]`, and define
`w_a[t]=D[t,a]/kappa_a` away from the pivot and zero at the pivot. The target
change `Q_a=I+w_a e_(p_a)^T` has an exact shear inverse. Exclusive pivots give
`w_a[p_b]=0` for every channel pair, so both cross-products vanish and all
`Q_a` commute. The pre-cut applies their inverses. The producer adds
`kappa_a f_a` only to its pivot, with `f_a` the actual current retained
source/dirty control. The post-cut applies the `Q_a`. The combined signal is
exactly `sum_a D[:,a] f_a`, while every old target value is preserved.
Independent corrections on nonpivots are unchanged during encoding. A
correction to a pivot between its cuts would be broadcast, and is rejected.

The local baseline contains three extra independently dirty sink coordinates.
They receive the three actual-row values, are read to targets, and are
restored before the full-frame basis inverse. The substituted word removes
only these destination-only copies. It does not remove the actual-row control
banks and does not discard kernel data. The complete original operator has
27 coordinates at `j3` and 35 at `j4`; the new operator has 24 and 32.
These counts include the sixteen arbitrary target banks, four/eight arbitrary
basis banks and four/eight read-only signal banks. Source aggregation and the
native signal-injection interface are unchanged external obligations.

The new old-response phase keeps every retained ancestor column
`-D C_active z`. Only the independent deleted sink column is absent. The
checker compares all original and substituted matrix columns, including all
dirty input coordinates. The original sink coordinates cancel from every
retained output and are individually restored in the baseline. Optional
nonpivot correction during encoding passes. Dropped ancestor responses,
omitted pre/post cuts and an early pivot correction all fail. All four
Gaussian fields and all real/imaginary components pass the complete word and
its chronological inverse.

All early old-response and pre-cut gates are assigned the identical actual
`F0=identity` representative. The basis, pivot producer and post-cut gates use
one identical actual `F_U`, with `dim(U)=5`, on every operand. Each local
target cap contains `U`, so later target transitions can continue to its
`T^perp` endpoint. The retained basis inverse and source cleanup occur at full.
These are explicit algebraic frame interfaces; large Gaussian address
matrices and fixed-tape streams are not materialized by this scalar checker.
Their native routing, payload, phase and precision bills remain separate.

The target pivot replaces its original first `[5]` child by the deleted sink's
prefix. Deleting the sink removes exactly `[5]` and `[h-5]` per completed
core. A more fragmented prefix cancels in the same way if the actual pivot
tracks every original write frame. For three sinks the local role change is
`-3`, the one-core rank change is `-3h`, and the three-core rank/capacity
changes are both `-9h`. The deficit is unchanged. The recorded minimal
ambient cases use `h14` at `j3` and `h12` at `j4`, giving rank changes `-42`
and `-36`. A larger host requires its full `[h-5]` endpoint charge, rather
than inheriting those smaller literal numbers.

For a subunit moment exponent, the six positive child pieces of each removed
three-core row have total width `3h`; their concave powers sum to more than
one normalized row. Thus the substitution can improve an already justified
profile's unnormalized slack without increasing its first-moment deficit.
No complete `k5` profile or transfer has been justified here, so this is a
conditional local leverage statement, not an exponent certificate.

The implemented complete scalar words have 272 to 281 gates at `j3` and 820
to 829 at `j4`: **nine more gates**. The retained old ancestor response is
explicitly expanded in this implementation. It does not inherit the upstream
`k+2` scalar-gate reduction, which uses a different existing expanded charge.
The complete new forward/inverse coefficient prefixes, including every
multiplication temporary, have row L1 at most 16/16 at `j3` and 32/32 at `j4`,
with at most three extra dyadic coefficient-grid bits. These are local scalar
charges relative to the incoming grid, not a full phase/rounding guard.

The complete original certificate serializes the forward scalar word under
the historical field name `all_forward_and_reverse_scalar_operations`. That
array contains the forward list only. The inverse is the exact reverse list
with negated shear coefficients and reciprocal unit scales, explicitly
executed by the checker. The source and original bytes remain unchanged;
publication summaries state exactly which long arrays are omitted.

The upstream proof requires disjoint target groups for simultaneous use.
Here the source-independent overlap calculation and exact finite checker
establish the weaker sufficient condition of exclusive pivots and shared
nonpivot destinations. This extension still requires source/dirty controls
independent of targets, a common-zero pre-cut, suitable pivot deadlines,
and every intervening correction at an actual frame contained in `U`.
The local component has that window. A target already at final `T^perp`
cannot be moved down to `U` for free. The global common-zero or interleaved
window is consequently the next required evidence.

The separate source
[`cap_interleaved_gossip_probe.py`](../../code/complex/cap_interleaved_gossip_probe.py)
provides a geometric sanity check. Choose four common paired coordinates and
one different fifth pair for each source cube. Each root is the selected
`j4` row. Targets use the four common first points and their corresponding
fifth point. Root `r`'s actual dimension-five cap is orthogonal to every target
except `r`; its row contributes to each other target. This is a genuine
paired-five incidence, not a synthetic compatibility graph.

With initially zero target **frames**, no clean target payload assumption,
the finite scheduler finds valid monotone common-frame read orders for two,
three and four roots. It visits 3, 31 and 1,528 memoized search states before
finding the witnesses; these are existence witnesses, not exhaustive
optimality counts. A literal binary-frame replay checks every union and
target-cap inclusion, and the complete root/target paths to full telescope
to one ambient width per role. It does not execute scalar dirty corrections
or a complete Gaussian word. Global central contributions and other source
cubes may close this optimistic window. The portable verification wrapper
also rejects missing, repeated or incompatible read edges.
