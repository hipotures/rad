# Independent analytical review of natural selected-fiber scan tapes

This receipt is a read-only analytical/source review of the three pinned
producer sources and their report. The producer was not imported or executed;
none of its record measurements was rerun by this reviewer. The exact input
identities are recorded in the accompanying protocol. Coordinator replay is
separate evidence.

The proposed endpoint is total-order prefix/difference within each fixed
spectator fiber, rather than Boolean subset zeta. In ordinary physical address
order, selected indices appear increasingly within a fiber. The compressed
spectator table index rises by one on spectator carries and falls by
2^(s_j-j)-1 on selected carries. Summing their exact counts gives backward
travel below M; the final table index and old-row wraps then give total
absolute row travel below 3M. Every traversal costs the whole actual record
width. Initialization emits one complete zero accumulator only at selected
index zero; no free key lookup or gathered payload order is assumed.

The literal counter walks only trailing bits, updates the aligned immutable
mask head and unary selected-one cursor, and returns both marked heads.
The zero predicate is a cursor-at-marker test. A selected carry's backward
countdown is the all-ones word in the lower spectator count. Real binary
borrow, its head returns, underflow cleanup and word erasure are implemented.
Aggregate trailing-bit work is O(M+n); decrement work is O(N_minus+M+n).
These sums establish the asymptotic metadata bill. This review does not claim
a new independent measurement or derivation of the producer's particular
finite monitor constant128.

The generic arithmetic consumer scans all signed component words until the
record marker, so arbitrary polynomial coefficient count does not become
machine tape count. Forward updates write the sum to accumulator/output;
inverse saves the current raw input while writing its difference from the
previous raw input. Original input is immutable and output copies every
original header bit. Accumulator headers need only have the common width;
selected bits in its stored selected-zero header are not used to key it.
The headerless adapter retains implicit physical labels instead. The final
rewind/erase visits actual scratch cells. Post-execution Python storage and
reference comparisons are monitors, separate from the tape consumer.

The standalone procedure has seven finite-alphabet tapes, ordinary blank
scratch and a table of complete volume2^-f times the current input. It is
not arbitrary-dirty reversible scratch. Full magnitude growth is2^f forward
and at most2 for difference, preserving the fractional grid. Reserving f+O(1)
integer/sign bits is required. Under the pinned w=Theta(p), f<=d=Theta(p^epsilon)
contract, record inflation is1+O(f/p)=1+o(1); the same statement would fail
for a component width only K. Descriptor/framing preparation, actual ancestor
guards and outer precision remain consumer obligations.

The source/report matches these premises and the ordinary-scratch endpoint.
It supplies no subset-zeta word, high-flux alternating address route, recursive
supplier or multiplier exponent. In particular, changing the pivot's physical
scan position can change the actual order; a high-flux consumer must restore
and bind its own original guard/control labels at its scan boundary.
