# Independent review of same-volume selected-bit guards

The coordinator accepts the guard allocation as a conditional layout and
stopping implication. The complete whole active Gaussian network remains
a required hypothesis. This review does not promote the proposed native
block, a characteristic root or a multiplication exponent to a theorem.

The producer [layout report](../transfers/guarded-slot-layout-transfer.md)
reserves existing complete chunks, not new address ranges. For
`e>=2h`, `f=floor(e/h)-1` and `u=e mod h`, the number of guard/remainder
selected kernels is `h+u<2h`. Each is one fixed two-address Gaussian map
on bit rho. It is not `C_K`. The primary elementary-stream contract permits
splitting on a specified binary digit, applying a fixed aligned map and
merging in O(V), with full records and allocated numerical guards.
The exact fixed-point format pays its shifts, reversals and temporaries.

For a rank-t child, the active set has tf axes. In the first tf physical
positions, every missing active axis is one of the existing periodic guards:
the interval ends before the first t slots end. At most t such holes occur.
The outside active donors have the same cardinality, so at most t full-K
exchanges compact the complete active set. Reverse exchanges restore every
address coordinate. Tensor C acts identically on each selected axis, so the
order of compacted active axes does not change its complete target.
These exchanges do not touch the preceding row prefix or add volume.

The actual child width satisfies `tf<=t*floor(e/h)` and `tf<e`.
For t=h it is at most `e-h`. Therefore every positive-power child
potential is no larger than the earlier profile majorant. This preserves
the existing stopped-tree proof only when its complete paid contracting
moment, row stock, local overhead and L-depth budget are already supplied.
Strict selected-width decrease alone gives neither that time bound nor
the O(d log d) precision allowance.

Applying guard kernels early is correct if the completed active block is
exactly `C_active tensor I_guards` on all current fields. Its endpoint then
commutes with the disjoint guard target even if its intermediate operations
use guard coordinates. Frame names or an operator valid only on zero guards
cannot satisfy this hypothesis. The literal tests substitute elementary C
for the missing block; they verify factorization, not a faster block.

An [independent geometry checker](../../code/obstructions/guard_slot_geometry_review.py)
imports no producer. It pairs guard holes in the reverse order from the
producer, verifies complete chunk return and exact rational majorants, and
checks 1,433 cases at h4/5/6/8. The producer/config bytes are read only to
bind their versions. [The complete independent run](../../runs/20261009T040434Z-independent-guard-geometry/report.md)
records the scope. The all-size argument above is mathematical review;
finite geometry enumeration is not formal verification.
