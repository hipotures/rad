## Required binary conditions

An unused-capacity parent P has at least two complete output-controller
chains. Select one chain whose first gate is F. Insert an explicit identical
sum P' immediately before F, assign it F's existing binary frame, and move
the complete selected chain. Choose another unused controller Q for the
other original scalar input before F. Add the two controller links
P_A -> P'_A and Q_B -> P'_B. All old selected links are retained. The exact
capacity and formal-child conflict audit guarantees one unused capacity per
provider and avoids changing another chosen clone's source identity.

This adds one logical sum and two retained links, hence saves one physical
role under R=c+q-links. The integer optimizer only proposes a feasible
compatible subset; every proposed subset is checked exactly. Its numerical
optimality bounds are not used as mathematical bounds.

For a nondegenerate binary frame U, c(U)=P_U 1. For nested nondegenerate
U contained in V, a positive residual is nonalternating precisely when
c(U) differs from c(V). Every newly used source-child interval and retained
link is checked separately with the established exact binary predicate.
The full physical timeline additionally checks every actual earlier frame,
fresh-role entry and terminal complement. Nonalternating admissibility is
not assumed transitive. Original frames remain on original nodes; clone
frames are existing first-consumer frames, so their Gram matrices and
projectors belong to the already reviewed family.

The new explicit graph preserves each input triple line and every D/E
