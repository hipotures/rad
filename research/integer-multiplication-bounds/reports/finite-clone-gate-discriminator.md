# Explicit duplicated gates can save physical controller roles

A duplicated cancellation-free sum need not increase physical roles. Let
P have at least two outgoing controller chains. Moving one entire chain to
an explicit duplicate preserves every existing output-side link. If each
new input recipient can capture a distinct previously unused earlier gate
capacity under the unchanged frame inclusion rule, the clone adds one
logical addition and two retained links. Thus R=c+q-links falls by one.
The duplicate has the same exact scalar value, core, support and source
provenance; its explicit DAG ID is never re-interned by formal support.

The broad [initial screen](../runs/20261008T040600Z-finite-clone-gates-small/protocol.json)
tested160 splits each at h8 and h12. Neither improves roles. Its negative
only covers the prescribed high-fanout/half/alternating/incomparable splits.
It is not a general duplication exclusion.

The [capacity-targeted discriminator](../runs/20261008T041600Z-finite-clone-residual-small/results/certificate.json)
finds three h12 and five h20 opportunities. Every separately tested clone
has delta additions1, delta links2 and role saving1, with all scalar,
forward/reverse physical frames and designated-target checks unchanged.
For example, h12 gate2167 moves its use at gate2463 and captures unused
capacities2201/2191. It changes R3804 to3803; the exact compiled SHA256 is
`33fed5f1090349ee144ba6c759da1dc8152da894aa021b76418f913b7e9fcd86`.

The [compatible batch control](../runs/20261008T042630Z-finite-clone-batch-small/results/certificate.json)
combines all three h12 clones: delta additions3, delta links6, R3804 to3801.
It passes independent dense logical, ordinary disjoint physical coefficient
and rational timeline replays. The complete side dirty basis has4241
coordinates, and the complete invocation including centers has4253
coordinates in both orientations. A neutral explicit h8 clone also passes
two full three-stage dirty exchanges. The same positive E(C,V) envelope
proof applies to duplicates, all original source lines and targets remain,
and arbitrary dirty L/J/L-inverse/V restoration holds for the new invertible
L. First/third bank matching is unchanged.

For a bounded completed reproduction, use the same source CLI with only

The [accepted h51 screen](../runs/20261008T043030Z-finite-clone-batch51/results/certificate.json)
reproduces its original compilation and finds zero two-predecessor
opportunities. The [accepted h50 screen](../runs/20261008T043600Z-finite-clone-batch50/results/certificate.json)
also finds zero. These are scoped negatives for this sufficient condition,
not a claim that the strongest odd/even graphs cannot be improved.

A second [controller-chain bridge screen](../runs/20261008T044000Z-finite-clone-bridge-small/results/certificate.json)
requires P's own capacity already retained on one input, so the clone can
insert itself into that input's existing chain while capturing one unused
predecessor on the other input. The sufficient algebra is valid, but none
of h8/h12/h20 instantiates its opposite-input premise. No large repeat was
launched for that uninstantiated mechanism.

These exact small improvements change the logical DAG and physical count
together. They do not yet improve the current accepted multiplication
bound, because the same sufficient condition has no witness on the best
large graphs. Any later large candidate must preserve the complete actual
count, dirty/frame/stage transfer and logical operation-depth guard.
