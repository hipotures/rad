# Boundary controls for the generic rational basis theorem

The frozen [generic-basis theorem](review-generic-metric-basis.md) survived
four targeted exact controls. They add no new primitive or final saving.
The [source](../code/review_generic_flag_boundaries.py),
[protocol](../runs/20261008T0640Z-review-generic-flag-boundaries/protocol.json)
and [certificate](../runs/20261008T0640Z-review-generic-flag-boundaries/results/certificate.json)
remain separate from the original executed pilot bytes.

Thirty-three full rational matrices use every bottom permutation at
kernel dimensions 1 through 4. Their front/back flags are invertible,
but the first off-diagonal pivot order varies. Each matrix has exactly
the claimed middle diagonal run and final zero rows. Independently
constructed lower factors verify `LAR=Pi` exactly. Both increasing and
decreasing first-block pivot orders occur. This confirms why the theorem
keeps those d pivots individual and does not infer one common ordering.

A singular ambient metric `G=diag(1,1,0)` supplies a real excluded case.
For the nondegenerate kernel line generated by e0, every projection
dual has last column zero. All 120 nonisotropic integer reflection
directions in the tested grid preserve that zero back flag. A full
back flag is impossible because the last column of G is zero. The
all-size theorem explicitly requires the ambient metric to be
nondegenerate, including when it is indefinite.

In characteristic two, all four nonisotropic directions of F2^3 make
the displayed reflection formula equal the identity: its coefficient 2
vanishes. Both initially deficient coordinate flags stay zero. The
rational finite-grid argument does not provide a native binary
complex-address theorem. The accepted construction instead selects
one fixed odd prime after the entire rational table is defined.

The final control isolates the necessary triangular-factor prime
exclusions. A rational rank 3 complement at dimension 5 has canonical
profile `(0,3),(1,4),(2,2)`. Every matrix-entry denominator is a unit
modulo 3, and reduction modulo 3 preserves rank 3, but the canonical
profile changes. One triangular factor has denominator divisible by 3.
Modulo 7, the complete lower-factor identity and old profile hold.
Thus checking only the incoming matrix denominators or final rank
does not suffice; the theorem's exclusion of all nonzero triangular
pivots and factor denominators is material.

The Python3.14.7 run finished in 0.15s, with 21424KiB peak RSS and zero
swaps, under one owned worker slot and a 16GiB address-space cap. The
slot was released. These are exact boundary controls, not an h51 basis
or factor-table instantiation. All setup qualifications and the earlier
primitive characteristic remain unchanged.
