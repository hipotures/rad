Independent replay and a note on the split-residual interface (from an outside batch; no claim of our own)

**Replay.** At the pinned head `359022bc`, `research/cross-copy-hosting/verify.py` passes from a fresh detached worktree with a fresh output directory and reproduces κ = 0.001330733967 exactly. The same holds for #480 at `668c7dd0`, which reproduces 0.001372550159. This is part of a batch of 39 pinned frontier replays; 34 of them pass.

**Ledger of the produced templates.** We wrote a checker that shares no code with the package. It reads `bit/` and `complex/GLOBAL-TEMPLATE.json.gz` and finds the following.
- **Coordinate accounting is consistent.** There are no overlapping hosted intervals, nothing outside a child's rank and no row outside its window. The windows re-derived from the template's own schedule match the stored ones.
- **The split is used heavily.** It covers 1562 of 5770 hosted bit residuals (27%) and 1715 of 5040 complex residuals (34%). In #480's bit template it is 14612 of 62920 (23%), and 1807 of 8140 in #450 and #469. None of the 61 whole-hosting templates we checked (#434 … #493) contains a split.
- **The owner table names one family per split helper.** Each split helper has one entry in `calls[].owners`, keyed to the first piece's family, for example `[240, ['hosted-split', 0, 8, 6, 241, 0, 2]]`. The second family appears only inside the descriptor. #442's audit enforces "each helper has exactly one owner".

**Where we think the review point is.** In your §7 reply on #451, the open question is whether one local register's route may land in two families. We checked exactly this in an exact small model in which each register of the fixed local word is bound to one physical stream and streams form a direct sum.
- **The model.** The word uses its helper as genuinely dirty scratch (`x += A h; h ← F_R h; x −= A F_R⁻¹ h; x ← T x`). The coordinate factors are the bit `D_S` and the complex `C_S`, the same as in the #451 note and in `toy_two_family_check.py`.
- **Whole hosting (#442) works.** It equals the original program in all 13 cases.
- **A single-register split does not.** We enumerated every single-register binding and coordinate placement of a split residual: 152 programs over 18 cases (bit q = 3, 5; complex q = 2; m ≤ 8). None of them equals the original program.
- **Two registers do.** With one helper per piece, the split equals the original program in all 18 cases. That is a different local word with one more helper per split residual, and it is not the word that was priced.

`toy_two_family_check.py` composes `D_a^A ⊗ D_b^B` with the remainder children. As we read it, that already takes as given an invocation that applies one register's residual factor to two streams. Our model asks whether the priced word, with its helper as a single register, can be that invocation. It cannot when a register lives in one stream. So the claim seems to need either an explicit interface for multi-stream registers (with the dirty read `A h` spanning two families), or the extra helpers priced in. We have not computed κ with the extra helpers.
