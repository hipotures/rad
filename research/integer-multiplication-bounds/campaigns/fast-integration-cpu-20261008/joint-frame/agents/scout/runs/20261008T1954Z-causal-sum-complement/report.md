## Regional invertibility and preservation of signals

At a region, let the distinct incoming physical roles carry scalar source
forms `f_1,...,f_n`. The compiler first chooses independent desired output
rows, preserving their original node labels. It then appends the matched carry
rows `e_i`; the original linear/partition matching oracle guarantees their
independence relative to the desired rows. This code is unchanged.

For each strictly later compatible actual consumer H, the new heuristic
offers `r_H=sum_{i: input_i also feeds H} e_i` over F2. It appends a candidate
only when it is independent of all rows already selected. It then offers
every standard unit row, so the final n-by-n matrix has full rank. The exact
same independence oracle checks every appended row. Gaussian row elimination
to the identity, reversed, synthesizes the matrix as literal XORs. Every row
swap uses three paid XORs. All incoming carriers have reached this region's
single original envelope before the synthesis; no local operation acts on
incompatible frames.

The desired and matched rows keep their original scalar signals and labels.
Only the added independent complementary rows receive the `retire` label.
They create no new requested or matched future-use assignments. Later reuse
still requires the original complete exact clearing relation and physical
frame inclusion; every clearing XOR is executed. The high-rank retirement
policy uses only such retired roles. This variant adds no external live-role
borrowing and therefore does not need a new live-donor continuation rule.

The future-consumer criterion chooses a useful complementary basis; it is not
an additional semantic oracle. Its indices and scalar graph are known finite
construction data. Removing that heuristic filter would choose another basis,
not itself prove illegal execution. Correctness instead depends on actual
matrix independence, requested/carry preservation, paid clearing, causal order
and physical frame containment. A singular complementary completion or an
unpaid basis change is inadmissible.

The complete original scalar DAG, all source triples, terminal incidences and
original envelope family remain unchanged. The root's complete Kahn order is
checked on every dependency edge before matching is recomputed. This mechanism
does not add an intermediate future-node evaluation or assume access to an
uncomputed scalar value. The common-consumer row is formed only from the
incoming roles already present at the region.
