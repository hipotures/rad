# Nested-frame component reclamation

The public PR58 compiler is the baseline. The original scalar graph, original
rational envelopes, source credits, and dirty scratch wrapper are retained.
This branch changes which existing carriers clear a retired component; it does
not assume that a scratch record contains zero.

## Evidence and status

The high-rank-first compatible-retirement rule changes the 23-axis compiler
from 30,790 to 30,688 roles. The complete literal word passes the producer's
indexed scalar check, its frame inclusion assertions, and its full arbitrary
dirty basis check in both orientations. A separate agent is replaying and
profiling this word. These checks do not yet establish a conditional exponent.

The low-rank-first rule changes the 25-axis compiler from 40,446 to 40,590 roles.
It also passes the producer checks and is retained as a negative. This shows
that clearing order matters even when every individual clearing is legal.

The controlled high-rank-first 25-axis counterpart instead gives40,338 roles,
108 fewer than the public baseline, in106.49 seconds. It passes the same
complete producer checks. The high-rank pair therefore has425,868 fewer
full-network roles after the inherited2,300 and1,771 axis multiplicities;
actual frame profiles and moments still determine whether it improves the
conditional bound.

Borrowing future live carriers, with the guard below and ordinary slot order,
changes the 23-axis compiler from 30,790 to 30,780 roles. It uses 118 borrowed
carrier XORs and retains every actual frame raise in its word. The 25-axis
counterpart gives40,476, a 30-role negative. Combined with high-rank retirement,
the rule gives30,711 and40,324 roles. The first is worse than pure high-rank
priority, while the second is14 roles better. Thus the benefits are not
additive. The small
7-axis control passes the full dirty and scalar checks, but uses no borrowed
carrier XOR, so it validates the implementation rather than the new benefit.

The corresponding compact receipts are in [results/](results/). Every receipt
pins the public source revision, base compiler hash, authored driver hash,
generated compiler hash, and the complete physical word hash. Words remain in
ignored execution storage and are deterministically regenerated by the

## A sufficient borrowing guard

Let a live carrier have current physical frame F and unchanged symbolic signal
z. Suppose a clearing operation takes place in frame G. Let H range over every
remaining use of that carrier, including its final output frame. It is safe to
use the carrier as an XOR source if

    F is contained in G, and G is contained in every remaining H.

Raise the source from F to G, and use the literal XOR in G. The source signal
z is unchanged by this operation. At each later use the source can still be
raised to H. Both the source and target frame changes are recorded and paid.
The guard applies to all outstanding assigned uses, rather than only the
next use. Uses already consumed in the topological order are omitted; terminal
outputs remain outstanding until final scatter.

The terminal condition is necessary for this one-way raising construction.
For example, a carrier whose final frame is F cannot be borrowed into a strict
superframe G: after the raise, G is not contained in F, and a later uncharged
lowering would violate the inherited physical contract. A signal-only scalar
check would miss this obstruction.

The new implementation first inserts local anchors, then eligible live
carriers, then compatible retired components into the symbolic binary basis.
When a retired component is dependent, it is cleared with the exact XOR
expression obtained from that basis. No new scalar node, computed-address
router, or growing advice table is introduced.

## Dirty scratch and causal scope

The compiler's symbolic zero only means that the retained linear combination
of input signals is zero. It does not mean that the actual scratch vector is
zero. The physical clearing operation is an invertible XOR word L. The
inherited complete wrapper uses L and its literal reverse around the scatter
and injection operations. The retained producer check evaluates every basis
vector of every input, output, and scratch role, in both orientations.

The borrowing guard proves that the changed source-frame trajectory remains
legal. The exact symbolic compiler invariants prove that desired signals are
preserved. Independent replay must still establish that the serialized events
and word encode those same trajectories. Complete fixed-I+J profiles and
the full moment and assembly calculation remain required before promotion.

## Why priority may help

Clearing a retired component can also raise other retired components that
appear in its XOR expression. Those moves affect which regions can reuse them
later. Ordering compatible basis candidates by decreasing current rank is a
concrete way to use carriers with less remaining frame flexibility first.
This explanation is a hypothesis for the 102-role result; the causal evidence
is the changed exact physical word, not a universal optimality claim.

The combined experiments keep the scalar graph and future-use guard fixed
while adding the high-rank retired order. A separate live-source ordering is
available for a later controlled comparison. The final profile can improve or
worsen even when the number of roles falls, so role counts are screening
measurements rather than a substitute for the recurrence moment.

Reversing the unit-vector completion order, while keeping requested output
rows and high-rank retirement fixed, gives31,023 and40,802 roles. These
controlled negatives retain the complete valid physical words. No further
unit-order sweep is planned in this branch. A separate
[future frame accessibility rule](future-frame-horizon.md) changes a structural
selection criterion rather than repeating those completion controls.

The repeated dirty scalar wrapper also needs an explicit all-size frame
schedule. The inherited common-frame identity applies to every physical gate
incidence, not just the first L word. It is insufficient to infer one charged
monotone path from scalar dirty correctness alone. The inverse agent is
checking a schedule whose first and last mixers run in common completed
frames, whose middle L follows the recorded paths, and whose copied centers
and ordinary outputs retain their full charged scatter/cleanup costs.
