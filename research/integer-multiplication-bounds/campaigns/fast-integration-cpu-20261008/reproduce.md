# Campaign reproduction

Run from this campaign directory. Python 3.11+ and a C++17 compiler are needed.
No Python dependency is required for the continuation investigation. Use a
fresh task-owned work directory for each attempt; existing outputs are retained.
The full campaign clock is observational and is not restarted by reproduction.

```bash

  --source work/reproduction-input/pr36 --work work/reproduction-matching \
  --output work/reproduction-matching-result.json --workers 4
```
