# Parameterized reversed h,h+2 geometry source interface

The eligible pinned PR40 source already contains a parameterized reversed boundary construction from James Chang’s PR34. The source functions are `corner_labels(h)`, `completion`, `check_cuts` in `research/copied-reversed/pr34/independent_controls.py`, and `geometry(h)`, `forest_rank`, `certify(h)` in its adjacent `certify_reversed.py`. [The source identities](parameterized-geometry-source.json) pin both the inherited author revision and the eligible input tree. These methods supply public geometry; this scout does not claim them as original.

For a=h,b=h+2, put m=h(h+2),d=2h+1. First-d labels are `[0,...,h−1,h−1,0,...,h−1]`; last-d inverse-column labels replace the middle h−1 by0. Their residue shift is `(m−d) mod b =3`. The prescribed labels complete to one controlled permutation for each residue. Both boundary graphs are trees. The exact incidence-cut certificates prove the right-of-prescribed-pivot zero identities for all diagonal weights. The resulting generic corner runs are nine singletons plus h−2 and h−6; the full data profile appends m−2d. This is precisely the inferred mass formula restricted to b=a+2. It does not supply arbitrary a,b geometry.

The source generic square/cubic nonvanishing witness does not certify the actual fixed I+J line pair family at a new dimension. Eligible `research/copied-both-reversed/geometry.cpp` supplies the complete finite proof strategy: enumerate every left and right triple, initialize the actual scaled d-by-d null corner, and execute every prescribed pivot at an admissible prime. A primary zero triggers a complete replay at another prime. Any complete successful replay proves the rational prefix minors nonzero; unresolved pairs fail. No CRT determinant magnitude bound is required for this one-sided nonvanishing test. Universal zero identities must remain separately proved by the incidence cuts.

Parameterization must replace all hardcoded dimensions, triple counts, expected zero-check counts and output metadata, and must derive the prime denominator checks from the new dimensions. The actual fixed line coordinate products at dimension h are `(6h−14)/(3(h+1))` inside the triple and `−5/(h+1)` outside it. Thus the scaled corner uses their reciprocals `3(h+1)/(2(3(h+1)−10))` and `−(h+1)/5`; these explicit numerator/denominator factors must be admissible at every selected prime. Retaining the original23/25 denominator list would be incorrect.

The actual local/auxiliary corner entry identities also parameterize to b=h+2: first-h/last-h corners have the second factor’s source indices i and j+2; first-b/last-b corners use first-factor index lists `[0,...,h−1,h−1,0]` and `[h−1,0,0,...,h−1]`. They should be checked using actual completed permutations for the new dimension, rather than inferred from tensor ranks. The fixed source line evaluations are nonzero for h≥6; copied-center formulas exclude h=9, as does the inherited form. Both dimension profiles, growth/auxiliary fronts, full copied-center output families, actual data geometry and the updated native compiler constants are required before promoting a complete bit saving.

This is a concrete source and proof interface, with no new dimension experiment or exponent claim. The source swap primitive does not state a coprimality condition on these two internal dimensions; the arithmetic prime CRT in the outer multiplication assembly is a separate construction.
