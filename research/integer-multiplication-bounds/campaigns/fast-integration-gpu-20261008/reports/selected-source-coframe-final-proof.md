## Exact source frames and selection

Let `H0=I-J/9`, fix a common coordinate `c`, and put `t_i=e_c+2e_i`
for `i != c`. Their column matrix satisfies `T^T H0 T=4I` and spans
`Gamma_c={x:sum(x)=3*x_c}`. On this positive space,
`x^T H0 x=sum_{i != c} x_i^2`. A source incidence `e_c+e_a+e_b`
equals `(t_a+t_b)/2`.

Each bipartite connected component of the outside source-incidence graph,
including an isolated vertex, supplies one disjoint alternating signed normal
`n`; odd components supply none. The exact source span has dimension
`h-1-number_of_normals` and projector

`P_source=P_Gamma-sum_n (T*n)*(T*n)^T*H0/(4*||n||^2)`.

The physical projector is `L_beta*P_source*L_beta^-1`. Independent controls
use an integer kernel basis and its Gram inverse instead of this subtraction
formula. Protected source, two-core and copied-center spaces are retained.
The frozen allocation selects **4988 / 7723** strictly smaller actual parent
frames. Every literal continuation has exact containment and satisfies
`minimum <= selected <= old actual frame` in the subspace order. The old
envelope is an upper bound, not a lower floor.

Choosing the minimum everywhere worsens moment despite reducing dimensions.
Profitable selection uses all four exact old/minimum transition costs,
singleton endpoint charges and hard containment implications. Some costs are
nonsubmodular. GPU populations and numerical MILP supplied discovery; the
frozen zero-based frame ID lists suffice for exact verification without a
solver or discovery cost table. No solver optimality claim is made.
