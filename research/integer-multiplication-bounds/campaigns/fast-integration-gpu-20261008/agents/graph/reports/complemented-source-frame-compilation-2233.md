# Joint compilation in exact source spans

The new construction replaces an original producer envelope with the exact
positive span of its primitive source lines. It does not require the
original envelope to be contained in that span. Every actual source and
scalar dependency must instead be reconstructed and included. The scalar
circuit remains Avi Eisenberg's pinned PR #62 interval/pair DAG; invertible
binary synthesis, carrier capacities and paid reclamation remain eumemic's
PR #57 compiler. This work was assisted by OpenAI Codex and preserves all
inherited author, license and assistance disclosures.

For a fixed common coordinate c, write T_i=e_c+2e_i for i outside c. With
H0=I−J/9, one has TᵀH0T=4I. The primitive source line {c,a,b} is half the
column sum T_a+T_b. Its outside-coordinate generator is therefore e_a+e_b.
The complete scalar source support defines an ordinary unsigned edge graph.

The orthogonal complement of these edge columns has one signed normal for
each connected bipartite component, including isolated vertices. An odd
component has no normal. Components have disjoint supports, so their normals
are orthogonal in the outside Euclidean metric. If their number is b, the
exact positive source span has rank h−1−b. Its H0 projector is

```
P_source = P_Gamma_c − sum_n (T n)(T n)^T H0 / (4 n^T n).
```

The rational basis L_beta conjugates this actual projector. Normal symbols
must never be interpreted as the direction symbols of an older signed frame.
The literal descriptor is `[rank, common_mask,
"complemented-signed-one-core-v1", signed_normal_symbols]`, and the complete
word is marked `mixed-signed-complemented-v1`. Sources and two-core frames
retain their previous distinct signed-direction descriptors. Native data
starts with the explicit `RADCOF01` magic and flags complemented frames in
the high bit of the forced mask; an old native reader rejects this format.

This family is closed under joins of source-edge spans: joining the spaces
is exactly the union of their source edge graphs. For example, two source
edges {1,2},{3,4} span two directions, as do {1,3},{2,4}. Their union is a
four-cycle with the single normal (1,−1,−1,1), giving a three-dimensional
join. A closure using independent direction classes instead gives four
directions and loses that normal. The exact
[rank-three join fixture](../fixtures/complemented-source-join-rank3-control-2233.json)
checks both inclusions, the strict non-inclusion in the opposite direction,
and all positive leading Gram minors.

The source compiler propagates positive source supports and the appropriate
outside edge graph for every common coordinate in each node's core. Each
addition requires disjoint primitive source supports. The graph union
constructs every one-core frame; two-core supports have their original exact
positive frame. Every scalar frame dependency is checked using an explicit
integer basis and exact normal equations. Equal actual frames then define
joint binary synthesis regions, and matching and paid reclamation are rerun.

The bounded h10 control passed exact source/scalar identities, actual frame
inclusions, output supports, endpoint dispatch and the full 1,810 binary
payload role basis in both orientations. It produced 1,570 paid roles and
1,685 regions. This is not an exponent claim. Full h23/h25 constructions are
running, with original and small-rise carrier choices. Their actual ordered
matrix profiles and complete recursive moments determine whether the smaller
frames help once every role and transition is charged.
