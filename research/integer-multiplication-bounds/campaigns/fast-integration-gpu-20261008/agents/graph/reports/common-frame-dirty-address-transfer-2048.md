# Arbitrary address arrays under common frame gauges

The literal-word receipts exhaustively check **2v+R abstract F2 role basis vectors** in both orientations. They also check exact rational frame bases, every actual containment, source/scatter compatibility and the executed transition multiset. They do not replay an additional basis vector for every rational direction or every physical address. These are distinct statements.

The inherited bridge is the common-gauge identity in public PR #62, pinned at `ad0f25ff7b23cff7f08ad237c2254e6ecf74257e`: `notes/endpoint-gauge-construction.tex`, “Exact lower-triangular conjugation” and “Complementary auxiliary gauges”; and `notes/structured-bulk-bit.tex`, “Retained scalar and partial-swap contract”. For a rational projector P, the partial address swap is

```text
D_P = [[I-P, P], [P, I-P]],       D_P² = I.
```

After reduction at a prime that preserves all required denominators and nondegeneracy, D_P is an address bijection. The bit payload remains F2. On any set of addresses, a common address permutation on both operands commutes with their pointwise scalar XOR. This holds for every input array, including components unrelated to any injected source line.

Place the same gauge on all incidences of each scalar XOR and insert the gauge changes on its physical wires. Each internal gauge and its inverse cancel in the composed word. Consequently, for the unframed scalar operator S, the framed array operator is

```text
U(D_out) (S tensor I_address) U(D_in)^(-1),
```

where U denotes the induced permutation of array addresses. This identity follows gate by gate and makes no restriction on the dirty arrays. It does not require internal gauges at different gates to commute. Nondegenerate nesting additionally gives `P_V P_U = P_U P_V = P_U` and `D_(P_V) D_(P_U) = D_(P_V-P_U)`, which is the charged residual-transition identity.

The scalar chronological word is `L, J, L^(-1), V` repeated twice. Its first section reads `JLz` and changes the logical auxiliary vector to `z+Vx`; its second reads `JL(z+Vx)` and restores z. Since `JLV=I`, the output change is x, independently of z. The exhaustive F2 role-basis replay verifies this scalar operator and its dual. Tensoring that verified linear identity with the identity on the address set proves pointwise cancellation for every dirty array. The reverse-complement orientation uses the transposed scalar shear and the inverse address gauges; the same common-permutation argument applies.

On an individually restored auxiliary role, the remaining physical endpoint action is `U(D_out D_in^(-1))`. The retained paired invocation prescribes complementary endpoint gauges, whose product is `D_I`. Thus “dirty restoration” means restoration in the prescribed logical endpoint interpretation, with the physical endpoint permutation paid by the inherited assembly. It should not be described as an independently replayed rational-address basis or as an uncharged identity permutation.
