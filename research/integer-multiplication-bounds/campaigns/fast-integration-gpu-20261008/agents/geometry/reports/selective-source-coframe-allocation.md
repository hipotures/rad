# Selective source-span frames for a fixed joint word

This construction changes actual rational address spaces on one fixed,
source-verified joint word. It preserves the scalar computation, selected
physical capacities, every literal XOR, source labels, copied centers and role
counts. The finite candidate at intake uses the matrix-weighted word with
dimensions 23 and 25 and bases beta = 1/15 and beta = -1/15. Acceptance also
requires the independent source reconstruction, stock interface and complete
assembly receipts; this note alone is not an exponent certificate.

## Source-span projector

Let H0 = I - J/9 and fix a common coordinate c. For i different from c, let
t_i = e_c + 2 e_i and write T for their column matrix. Direct multiplication
gives T^T H0 T = 4 I. Consequently the full one-core space Gamma_c is positive,
and every subspace used here is positive as well.

The source vector for U = {c,a,b} is (t_a+t_b)/2. For an unsigned graph on the
outside coordinates, its edge-incidence span therefore contains exactly these
source vectors. The orthogonal complement has one signed normal on each
bipartite connected component, including isolated vertices; an odd component
has no normal. If A consists of these disjoint signed row normals, the exact
source-span projector before changing basis is

    P = T (I - A^T (A A^T)^-1 A) T^T H0 / 4.

The actual address projector is L_beta P L_beta^-1. The independent verifier
constructs a kernel basis B of A and instead computes B(B^T H0 B)^-1 B^T H0
in ambient coordinates. Thus it does not merely read the native complement
formula back. Ordered northeast pivots and recursive widths are recomputed
from the resulting actual transition matrices.

## Safe replacement and selective restoration

The portable constructor `fixed_word_source_coframes.py` starts from the
actual selected signed frames of the source-bound parent, not from an
unsigned original-envelope template. Source frames, frames with two or more
core coordinates and copied-center frames are protected. It seeds source
incidence components and propagates them along every literal physical frame
continuation. A proposed enclosure is accepted only when it contains its
actual predecessor and lies inside the parent's actual selected space.
Otherwise the old signed frame is retained. The constructor also preserves
the strict positive growth required by this physical transition encoding.

This produces a consistent minimum choice M_i inside every old actual frame
O_i. The word-wide uniform minimum is a useful negative control: smaller
address ranks alone worsen the complete ordered moment in both dimensions.

`partial_fixed_word_coframes.py` chooses either M_i or O_i. The selected
policy protects ordinary terminal frames, has rank cutoff zero, and restores
O_i when the removed one-dimensional H0-orthogonal direction has coordinate
sum zero. It then restores every recipient needed for containment and strict
growth. The policy is an empirically useful exact flag, not a claim that
balanced directions always have a particular transition cost. For every
literal continuation the chosen spaces remain nested, and

    M_i is contained in the chosen frame, which is contained in O_i.

There is no assertion that O_i is contained in its replacement. All source
and ordinary endpoint predicates, copied centers, physical capacity uses,
forward and reversed dirty words are independently checked on the new word.
Arbitrary input arrays retain the inherited contract. No ridge restriction
and no unpaid terminal frame shrink is introduced.
