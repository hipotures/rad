## Construction and checks

Each region has its actual containing signed positive frame, with forced set F
and columns `B_l = tau_l 1_F + (3-|F|) epsilon_l`. The H0 Gram matrix is
`(3-|F|)^2 diag(n_l) + (|F|-1) tau tau^T`; for two forced coordinates this is
`diag(n_l) + tau tau^T`, which is positive definite. The base assignments use
the exact selected multifamily choices. A chosen two-core region activates
additional whole classes of its actual maximal source partition.

The constructor propagates each new column's necessary support to successor
regions, activating complete recipient classes until no new class is required.
It includes the forced support when the signed class sum is nonzero. It then
independently checks original/base/selected/maximal containment and every
actual transition containment. Support propagation alone is not accepted as
a proof of containment. The literal signed word is rebuilt and independently
replayed for source identities, physical roles and arbitrary dirty restoration
in both orientations. Every changed matrix profile is recomputed by the full
native rational/CRT compiler, including cleanup and output-side charges.

The chosen h23 variant selects pair (20,21). The chosen h25 variant selects
pairs (3,4) and (3,5). Both use mode `all` and threshold 0 on the actual original
region rank; their bases remain 1/15 and 7/207. The full source-labelled
configuration is `../configs/selected-coupled-pair-core-portable.json`.
The unchanged roles are R23=27,719 and R25=36,353.

These are bounded partial pair frames. For example, the h23 selected pair
regions have ranks 2,5,7,...,19, rather than a full rank h-2 pair frame. A failed
initial targeted-control locator incorrectly required full rank h-2; its
preserved failure is an instrumentation error, not a mathematical rejection.
The corrected selector tests the actual nonzero two-core endpoints.
