sprint's ignored `work/module/`. The coordinator owns Git and scientific

six long-diagonal signed channels, and single-use positive triple-gate

the full finite signed/dirty/geometry checks, but their rigorous finite

rejects the required complex savings `655831073/10^12` and
`655861417/10^12`. No conditional or publication candidate is claimed.
