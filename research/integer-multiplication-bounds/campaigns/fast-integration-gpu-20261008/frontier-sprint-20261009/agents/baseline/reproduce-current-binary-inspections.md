# Reproduce the current binary partial inspections

Use standard-library Python with assertions enabled. Python 3.14.4 was
exercised. Run from the sprint directory. This path reproduces GRAPH_ONLY and
SCALAR_ONLY evidence, not a complete candidate or exponent acceptance.

Obtain immutable source tarballs through the GitHub CLI:

```bash
gh api repos/eumemic/integer-mult-bounds/tarball/91f6a059f44fb0513639d5185bde2a38973e99ca > /path/to/source91.tar.gz
gh api repos/eumemic/integer-mult-bounds/tarball/fd25adb7fbaa12ee761d02c733c54d1d2a7687ee > /path/to/sourcefd.tar.gz
```

Extract them into separate fresh directories. Verify the two source closures
in `configs/current-binary-inspection-pins.json`. The graph inspection imports
none of the downloaded Python; the generator hash is an identity gate and the
pair module is independently checked as finite DAG data.

For each `graphs` record, recover its actual graph through the exact pinned
source path or the complete `recovery.gzip_path`. The entrypoint accepts either
JSON or its whole gzip evidence copy and verifies the decompressed SHA-256.
The changed graph files are also deterministically regenerated by the linked
bit-agent reproduction commands. Verify a complete evidence namespace before
extracting it with `tools/archive_workspace.py verify-text --destination ...`.

Set task-specific source and output locations:

```bash
TASK_REVIEW_SOURCE91=/path/to/eumemic-91f6a05
TASK_REVIEW_SOURCEFD=/path/to/eumemic-fd25adb
TASK_REVIEW_OUTPUT=/path/to/fresh-partial-review
mkdir -p "$TASK_REVIEW_OUTPUT"
python3 agents/baseline/code/inspect_current_binary_adapters.py \
  --pin agents/baseline/configs/current-binary-inspection-pins.json \
  --output "$TASK_REVIEW_OUTPUT/source91.json" graph --case source91 \
  --source "$TASK_REVIEW_SOURCE91" \
  --graph "$TASK_REVIEW_SOURCE91/research/paired-cube-bit/out/graph_p12.json"
python3 agents/baseline/code/inspect_current_binary_adapters.py \
  --pin agents/baseline/configs/current-binary-inspection-pins.json \
  --output "$TASK_REVIEW_OUTPUT/sourcefd.json" graph --case sourcefd \
  --source "$TASK_REVIEW_SOURCEFD" \
  --graph "$TASK_REVIEW_SOURCEFD/research/paired-cube-bit/out/graph_p12.json"
```

Repeat the same graph command with `--case thirdfusion`, `remove01_0`,
`remove01_1` or `add02_0`, the fd25 source, and the corresponding recovered
graph path in the pin manifest. Every command must produce `PASS_GRAPH_ONLY`
and reject the actual wrong producer policy. Output files must not already
exist.

The exact physical input directory is recovered from
`scalar.recovery.whole_gzip_export_directory`. Decompress the five whole
exports into a fresh directory without changing their original bytes. Each
name and hash is in `scalar.export_sha256`. The physical profile is generated
by the source-bound control and archived there; it is not present as a
standalone profile file in the downloaded physical-source folder. The linked
bit control reproduction regenerates all five exports if desired.

```bash
TASK_REVIEW_PHYSICAL=/path/to/recovered-five-physical-exports
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python3 agents/baseline/code/inspect_current_binary_adapters.py \
  --pin agents/baseline/configs/current-binary-inspection-pins.json \
  --output "$TASK_REVIEW_OUTPUT/scalar.json" scalar --export "$TASK_REVIEW_PHYSICAL"
```

Expected result: `PASS_SCALAR_ONLY`, 21,812 formal variables in each
orientation, 115,412 literal events, 1,760 compensated recipients, and program
hash `f7d462a3bbb57c50c263a0eced44db8d8e3203b4caeca55cd5e3ee0167c8e92a`.
The command also mutates an actual compensation event and checks rejection in
both orientations.

`python3 -O agents/baseline/code/inspect_current_binary_adapters.py` must reject
with `assertion-disabled execution rejected`. In copied execution inputs,
appending a space to the pair module or graph must reject its corresponding
source/input hash gate. Appending a comment to a copied reviewer dependency
must reject that dependency's hash gate. Restore original copied bytes after
each control. Do not edit the immutable source or durable reviewer files.

The retained clean recovery receipt lists the actual commands, hashes and
control errors. Its 3.05-second run relocated all eight reviewer files and
used only the two small source closures plus recovered complete data fixtures.
No full carrier, complemented physical geometry, prime, paid ledger, moment,
bridge or final exponent check is implied by this path.
