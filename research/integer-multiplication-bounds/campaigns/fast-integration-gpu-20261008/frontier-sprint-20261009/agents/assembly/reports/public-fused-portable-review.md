```text

```

Retain their [license](../LICENSE) and [attribution notice](../NOTICE). From a
directory containing the normalized package, run:

```bash
python3 independent/review_public_fused.py \
  --directory research/lifetime-fused-frames/transfer \
  --output fresh-independent-review.json
```

The output path must be fresh. No campaign checkout, external package, upstream
Python module or private environment setting is needed by this command.
