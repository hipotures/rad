# Exact universal phase precision allowances

All affine exponent comparisons pass at p=101 and are nonincreasing thereafter. Thus the positive-power inequality p^k<=2^(kp) gives universal integer-p certificates for the displayed local, completed-map, rounding, gap, factor inverse and final error allowances. This checks scalar arithmetic; matrix identities and tape cost are independently reviewed.
