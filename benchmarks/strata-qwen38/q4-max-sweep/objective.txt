2. KLUCZOWE PYTANIE ARCHITEKTONICZNE
============================================================

Sprawdź w aktualnym kodzie dokładnie, jakie ExpertSource / host arena
są dostępne dla native GGUF pack bez experts.bin.

Chcę wiedzieć, czy Q4 może działać jako:

GPU0 expert cache
+
GPU1 expert cache
+
CPU/RAM fallback

BEZ:
  --resident-cpu-experts
  --resident-budget-gib

Wiemy już, że `resident-cpu-experts` jest jawnie niekompatybilny z:
- layer split;
- remote expert caches.

Nie próbuj usuwać tego guarda.

Interesują nas zwykłe upstreamowe ścieżki, które NIE używają
resident-cpu-experts.

Przed benchmarkiem zapisz krótki:
  architecture-notes.md

z dokładnym opisem:
- skąd przy każdym trybie pochodzą bytes ekspertów;
- które ekspery są GPU-resident;
- które liczy CPU;
- czy CPU czyta z RAM/page cache czy bezpośrednio powoduje file reads;
- czy native GGUF może mieć pełną host arena bez experts.bin;
- czy jest tylko mmap/page-cache path;
- jakie ograniczenia istnieją dla multi-GPU.
