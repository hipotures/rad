# Native Q4 architecture — frozen Strata v0.1.32

HEAD c499bd102e7a4135c0de389dcfe38c399759ccc8. No engine modifications. These notes revalidate the relevant paths against the new checkout, rather than copying a v0.1.31 claim unchanged.

Default full arena: generate.cpp2556–2602 constructs ArenaExpertSource, sets native GGUF spans and opens all48×512 expert blobs without --mmap-experts. expert_source.cpp2151–2222 loads native spans into allocated host RAM, and blob() at2279–2289 returns pointer arithmetic into that loaded arena. experts.bin is not required. Linux normally registers the whole arena; recorded startup says cudaHostRegister PORTABLE and71.73GiB loaded. GPU0/GPU1 hot expert caches compute their own layer ranges; CPU misses read RAM, with a configured PCIe fraction eligible for GPU computation from RAM. No per-token routed expert file fetch is needed in this mode.

Resident budget mode is a different path: it implies file-backed mapping plus resident CPU complement, excluding GPU-held pairs from that complement. An80GiB budget is not proof that all72GiB are duplicated in RAM; the cache+RAM complement union can cover the whole set. The upstream guard still rejects resident-cpu-experts with layer split or helper cache (generate.cpp1319–1335). This restriction is not bypassed. SingleGPU resident baseline is separate from default multiGPU full arena.

Native mmap path (generate.cpp2558–2575) maps checked GGUF spans in place even without experts.bin. File-backed bytes may be served from OS page cache; logicalfetch is not physicalSSD traffic. Fullarena and mmap must not be described as the same host source.

Split means contiguous layer ownership and separate expert caches; CPU fallback pool and one host arena are shared. Normal cache_hits counts kind0 GPU-cache routed entries; cache_refused increments only for kind<0 CPU routed entries (expert_source.cpp1744–1754). PCIe kind1 and remote kind2 results are excluded from this cache+CPU denominator. Thus printed hitpercent is not an exact partition of ALL routed work, and lookup-minus-hit is CPU routed entries, not all GPU-cache misses. Normal per-GPU routed hit counts are unavailable; they remain null. Per-stage timing lines may accumulate across engine lifetime.

KV geometry is48layers, everyfourth QSA, hence12QSA layers; two KVheads, head_dim256 (include/strata/core/layout.hpp). INT8 is1056B/cell/layer including K/V scales. Hybrid K8V4 is816; rotatedQ4_0 is576 (include/strata/core/layer.hpp and include/strata/kernels/kv_q4.hpp; conversation_snapshot.cpp41–65). RotatedINT8 uses the same payloadsize asordinaryINT8, with different rotation semantics. Estimated logical K/V payload = actualpositions×12×bytes_per_cell; it excludes indexer/GDN/state/checkpoints/pagepadding and is not measured VRAM or total KV allocation. K8V4+kv-resident is explicitly unsupported.

PLE remains a distinct native mapped table. Serve-mode request-end expertfilecounters cannot attribute prefill/PLE traffic separately. Physical hostSSD behindvirtiofs cannot be proven from zero expert file_blobs, nor from process read_bytes, which includes unrelated files. Main matrix/expertSSD conclusions must retain these limits. Official STRATA_PREFILL_TIMING and normal decode/stage metrics are used only at their documented scope; separate diagnostic timings are excluded from performance ranking.
