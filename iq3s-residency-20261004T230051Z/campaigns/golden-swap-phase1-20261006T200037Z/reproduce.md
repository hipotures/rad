Analysis commands regenerate derived artifacts explicitly. Replay launchers never build or update anything. No normal serving launcher enables this scorer.

Each command creates a new sibling reproduction directory. It verifies binary/source/model/checkpoint identities and effective settings, refuses conflicting GPU/port ownership, uses fresh-server/saved64-token warmup/full replay, caps startup+warmup at180s and request at240s, validates complete work and initial state, then stops only its own processes.
