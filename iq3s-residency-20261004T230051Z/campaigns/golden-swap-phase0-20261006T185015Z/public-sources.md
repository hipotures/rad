# Public source collections inspected and selected

Discovery used two collections, below the maximum four. Downloading selected sources took seconds rather than a full benchmark installation. No reference answers, gold patches, hidden tests, paid services or prompt uploads were used. These are routing tasks, not official benchmark scores.

1. **RFC Editor official collection**: https://www.rfc-editor.org/ . Reused local RFC 9111 (HTTP caching) with its original source snapshot. Downloaded immutable https://www.rfc-editor.org/rfc/rfc8446.txt (TLS 1.3), https://www.rfc-editor.org/rfc/rfc6455.txt (WebSocket), and https://www.rfc-editor.org/rfc/rfc8941.txt (Structured Fields). Exact URLs, bytes and SHA256 are in provenance/public-downloads.json. Copyright/license notices are part of each saved document: IETF Trust Legal Provisions. Adaptations are new task wrappers and one complete-paragraph WebSocket prefix to leave output/reserve room. No document repetition/padding. Translation is tagged English-to-Polish.
2. **Chinook official repository**: https://github.com/lerocha/chinook-database . GitHub REST reads used gh. Pinned commit is in provenance/chinook-sha.txt and confirmed again after download; version1.4.5 SQLite script is corpus/chinook.sql. The selected task uses its real DDL prefix before INSERT rows, not random JSON or fabricated logs. No database runtime or full dataset environment was installed. Complete permission text is corpus/chinook-LICENSE.txt; GitHub classifies it NOASSERTION, so the manifest retains the actual Chinook permission/license instead of trusting an SPDX guess. The notice permits reuse/modification with its copyright notice and disclaimer.

Previously local source collections (CPython/NumPy source snapshots, HEG repository and HTTP RFCs) were inspected via immutable historical files. Their original revision may be unavailable; exact snapshot hashes are retained rather than inventing one. Existing authored mathematical problems are explicitly local research problems, not claimed to come from a public benchmark. The real build log is local evidence, inspected for credential patterns and never uploaded.
